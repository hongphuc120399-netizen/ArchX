# Thư viện Dự án Kiến trúc

Bộ sưu tập các dự án kiến trúc được phân loại theo từng loại công trình.

---

### Hướng dẫn sử dụng

1. **Thêm hình ảnh**: Đặt hình ảnh vào các thư mục tương ứng:
   - `1. BIỆT THỰ/` - Dự án biệt thự
   - `2. NHÀ PHỐ/` - Dự án nhà phố
   - `3. Công Trình Công cộng/` - Các công trình công cộng

2. **Cập nhật thư viện**: Chạy lệnh sau để tự động tạo lại thư viện:
   ```bash
   python3 generate_gallery.py
   ```

3. **Lưu ý**: Chỉ hình ảnh trong 3 thư mục trên mới được hiển thị. Hình ảnh ngoài các thư mục này sẽ bị bỏ qua.
