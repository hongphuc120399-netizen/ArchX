# ArchX - Nhà Phố Gallery

Vietnamese Townhouse Architecture Gallery featuring 34 beautiful townhouse designs.

## Features

- **Interactive Gallery**: Browse through 34 stunning townhouse architectural images
- **Embed Codes**: Each image has a "Show Embed Code" button that reveals the embed link
- **Responsive Design**: Beautiful grid layout that adapts to different screen sizes
- **Hover Effects**: Interactive hover animations on images
- **Modern UI**: Clean, professional interface with gradient background

## Usage

### View the Gallery
Open `index.html` in your web browser to view the gallery.

### Get Embed Links
1. Browse the gallery
2. Click "Show Embed Code" button under any image
3. Copy the HTML embed code
4. Paste it into your website or blog

### Embed Code Format
All images are available via GitHub raw URL:
```html
<img src="https://raw.githubusercontent.com/hongphuc120399-netizen/ArchX/main/[IMAGE_NAME].jpg" alt="Townhouse">
```

## Image Categories

All 34 images showcase various styles of Vietnamese Nhà Phố (Townhouse) architecture:
- Classical/Ornate Vietnamese designs
- Modern contemporary styles
- French colonial influenced townhouses
- Row townhouse developments
- Multi-story residential buildings
