### Get All URLs as JSON
```bash

```

### Use in HTML
```html

     alt="Villa Architecture">
```


## 💡 Usage Tips

1. **Performance**: Images are high-resolution. Consider using thumbnails or lazy loading for better performance.

2. **Caching**: Implement browser caching or use a CDN for production applications.

3. **Responsive Images**: Use `srcset` or responsive image techniques for different screen sizes.

4. **CORS**: GitHub raw URLs support CORS, so they're safe to use in web applications.

5. **Rate Limiting**: Be aware of GitHub's rate limits. Cache images locally for high-traffic applications.
