🔗 ArchX Embeddable Links Demo

This page demonstrates how to use the embeddable GitHub raw URLs in your applications.

✅ Example 1: HTML Image Tag

You can use the URL directly in an HTML <img> tag:

<img src="https://raw.githubusercontent.com/hongphuc120399-netizen/ArchX/main/0777b59e06ec8ab2d3fd.jpg" alt="Villa">

Result:

✅ Example 2: CSS Background

Use in CSS for background images:

background-image: url('https://raw.githubusercontent.com/hongphuc120399-netizen/ArchX/main/1976427df50f7951201e.jpg');

✅ Example 3: JavaScript Fetch

Load images programmatically with JavaScript:

fetch('https://raw.githubusercontent.com/hongphuc120399-netizen/ArchX/main/3a0c7d6ec81c44421d0d.jpg') .then(response => response.blob()) .then(blob => { const img = document.createElement('img'); img.src = URL.createObjectURL(blob); document.body.appendChild(img); });
