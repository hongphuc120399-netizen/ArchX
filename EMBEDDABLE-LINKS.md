# ArchX - Embeddable Image Links

This file contains actual HTTP URLs that can be embedded directly into your applications.

## 🔗 Usage

All images are hosted on GitHub and can be accessed via raw URLs. These links can be used in:
- HTML `<img>` tags
- CSS `background-image`
- Markdown image syntax
- JavaScript fetch/axios requests
- Mobile app image loaders
- Any HTTP client

## 📋 Base URL

```
https://raw.githubusercontent.com/hongphuc120399-netizen/ArchX/main/
```
